## ڈیٹا کے ذرائع ایک نظر میں

| ذریعہ                                                                                                                        | یہ کیا دیتا ہے                                                                                       | ضرورت                                     |
| ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **HT Sim** (فیوچرز: CLZ6, GCZ6, ESZ6, NQZ6)                                                                                  | Seed شدہ، حقیقت سے قریب ٹریڈز اور depth؛ آف لائن چلتا ہے، پیپر اکاؤنٹ                                 | کچھ نہیں                                  |
| **Crypto Sim** (BTCUSDT)                                                                                                     | کرپٹو کے لیے وہی                                                                                     | کچھ نہیں                                  |
| **کرپٹو ایکسچینجز** (Binance spot / USDⓈ-M / COIN-M, Bybit, OKX, Bitget, Bitfinex, Kraken Futures, Deribit, Phemex, Whitebit) | live پبلک ٹریڈز اور آرڈر بک، فنڈنگ، اوپن انٹرسٹ، اور جہاں ایکسچینج شائع کرے وہاں لیکویڈیشنز           | انٹرنیٹ۔ مارکیٹ ڈیٹا کے لیے API کلید نہیں |
| **CSV درآمد**                                                                                                                | آپ کے اپنے ٹریڈز یا OHLCV بارز بطور انسٹرومنٹ                                                        | ایک فائل                                  |
| **Custom WebSocket**                                                                                                         | کوئی بھی JSON فیڈ جسے آپ ٹریڈز / depth سے میپ کریں                                                   | `ws://` یا `wss://` URL                   |
| **فیوچرز اور اسٹاک بروکرز** (Rithmic, CQG, Tradovate, Interactive Brokers, dxFeed, …)                                        | صرف روڈ میپ دکھانے کے لیے درج ہیں                                                                    | وینڈر SDK یا لائسنس؛ ابھی جڑے نہیں        |

> **نوٹ** ایکسچینجز سے live کنکشن ڈیسک ٹاپ ایپ میں کام کرتے ہیں۔ براؤزر پری ویو ایکسچینج APIs تک نہیں پہنچ سکتا (CORS)، اس لیے وہ صرف سمیولیٹر دکھاتا ہے۔ ٹریڈنگ ہمیشہ پیپر انجن پر ہوتی ہے۔

## Connections ونڈو

اسے ربن (**Connections**) سے یا اسٹیٹس بار کے کسی pill پر کلک کر کے کھولیں۔

![Connections ونڈو](images/connections.webp)

- **+ Add connection** ایک وزرڈ شروع کرتا ہے: پرووائیڈر چنیں، مارکیٹ منتخب کریں، چاہیں تو ٹیسٹ سمبل لکھیں، **Test** کریں، پھر **Save**۔
- **Connect all / Disconnect all** اور **Auto-connect on start**۔
- ہر قطار اسٹیٹس، latency، فی سیکنڈ پیغامات اور اکاؤنٹس دکھاتی ہے؛ **Edit** اسے بدلتا ہے، ✕ ہٹا دیتا ہے۔
- نیچے کی ٹائلز live کنکشنز، اوسط latency، فی سیکنڈ پیغامات اور آج دوبارہ sync ہونے والے gaps دکھاتی ہیں۔
- **Data manager** ٹیب بتاتا ہے کہ مقامی طور پر کیا محفوظ ہے (دیکھیں [Data manager](14-data-manager.md))۔

![کنکشن شامل کرنے کا وزرڈ](images/connections-wizard.webp)

جو اسناد آپ درج کرتے ہیں (مثلاً Telegram ٹوکن یا ٹریڈنگ کے لیے ایکسچینج کی کلید) وہ آپ کے انکرپٹڈ vault میں جاتی ہیں، سادہ فائلوں یا لاگز میں کبھی نہیں۔

## سمبلز اور انسٹرومنٹ پکر

ونڈو ہیڈر میں انسٹرومنٹ کے نام (مثلاً `CLZ6 ▾`) پر کلک کریں تاکہ پکر کھلے:

- **گروپ ٹری** (فیوچرز، کرپٹو ایکسچینجز، ...)، ساتھ **All / Favourites / Recent**۔
- ہزاروں سمبلز میں **غلطی برداشت کرنے والی تلاش**۔
- ستارہ پسندیدہ میں شامل کرتا ہے؛ **Has live feed** فلٹر وہ قطاریں چھپا دیتا ہے جن کی فیڈ نہیں۔ اسٹیٹس کالم Live، Sim، Delayed، Replay یا No feed کہتا ہے؛ بغیر فیڈ والی قطاریں Connections کا راستہ دکھاتی ہیں۔
- پکر سے سمبل کو کسی ونڈو پر گھسیٹیں تاکہ اس کا انسٹرومنٹ بدلے، یا نیا چارٹ ونڈو بنانے کے لیے `Ctrl` دبا کر چھوڑیں (یا خالی ڈاک جگہ پر چھوڑیں)۔
- کمانڈ **Refresh symbol list (all exchanges)** ایکسچینجز کے exchange-info endpoints دوبارہ پڑھتی ہے۔

فیوچرز کنٹریکٹس کیٹلاگ کے roll قواعد کی پیروی کرتے ہیں؛ فرنٹ منتھ خود بخود چنا جاتا ہے۔

## ہسٹری

جب آپ کسی live ایکسچینج پر چارٹ کھولتے ہیں تو HT Flow پہلے **مقامی tick store** میں جو کچھ موجود ہے وہ پڑھتا ہے، صرف غائب gaps ایکسچینج کے پبلک REST API سے ڈاؤن لوڈ کرتا ہے، پھر live اسٹریم پر چلا جاتا ہے، جوڑ پر نہ کوئی خلا رہتا ہے نہ ڈپلیکیٹ۔

- **◂ Load 1 more day** اور **Load days** (نچلی بار) پرانی ہسٹری لاتے ہیں؛ بائیں اسکرول کرنے پر مزید خود بخود لوڈ ہوتی ہے۔
- `Ctrl+G` (**Go to date**) کسی تاریخ پر جاتا ہے اور اسے لوڈ کرتا ہے۔
- **Reload all historical data** نظر آنے والی رینج دوبارہ ڈاؤن لوڈ کرتا ہے۔
- تقریباً پچھلے ایک دن سے پرانے دنوں کے لیے ایکسچینجز ٹریڈز کی بجائے کینڈلز دیتے ہیں۔ Binance کی کینڈلز میں اصل taker تقسیم ہوتی ہے؛ دوسرے ایکسچینجز پر پرانی بارز کی buy / sell تقسیم کا تخمینہ لگایا جاتا ہے۔ Tick recorder آپ کا live ڈیٹا محفوظ کرتا ہے تاکہ بعد کے سیشنز میں درست ٹریڈز ملیں۔

![تاریخ پر جائیں](images/go-to-date.webp)

## ٹائم فریمز اور بار کی اقسام

ہیڈر کے chips (M1, M5, H1 …) ٹائم فریم بدلتے ہیں؛ **TF** مکمل ڈائیلاگ کھولتا ہے جس میں ہر بار کی قسم کی قطار ہے: Time, Tick, Volume, Delta, Range, Range X / XV / Z / US, Renko, Reversal, Order Flow, Cumulative Trades, Heikin-Ashi, Point & Figure, Kagi اور Line Break۔ **Configure** chips شامل یا کم کرتا ہے اور پسندیدہ کو ہیڈر میں پن کرتا ہے۔ اگر فیڈ وہ بار کی قسم نہیں دے سکتی تو chip دھندلا ہو سکتا ہے۔

![ٹائم فریم ڈائیلاگ](images/timeframes.webp)

## ٹریڈنگ سیشنز

نچلی بار کا سیشن سلیکٹر کیٹلاگ میں ایکسچینج کے قواعد کے مطابق **24H**، **ETH**، **RTH** یا **Custom** سیشن (کھلنا / بند ہونا / ٹائم زون / دن) میں بدلتا ہے۔
