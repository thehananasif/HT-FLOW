سیٹنگز `Ctrl+,` سے یا `Ctrl+K` ← `Settings: <section>` سے کھولیں۔ تلاش کسی بھی سیٹنگ کو نام سے ڈھونڈ لیتی ہے۔ تبدیلیاں **مسودے** کی صورت میں رہتی ہیں جب تک آپ **Apply** یا **OK** نہ دبائیں؛ **Cancel** انہیں ختم کر دیتا ہے۔ بدلی ہوئی سیٹنگز نشان زد ہوتی ہیں، اور ہر ایک کو الگ سے، سیکشن کے لحاظ سے یا سب ایک ساتھ ری سیٹ کیا جا سکتا ہے۔ سیٹنگز ہر یوزر کے لیے (انکرپٹڈ) محفوظ ہوتی ہیں اور ہر key کی توثیق کے ساتھ JSON میں ایکسپورٹ اور درآمد کی جا سکتی ہیں۔ پیلیٹ کی تلاش انفرادی سیٹنگز بھی ڈھونڈتی ہے۔

![عمومی سیٹنگز](images/settings-general.webp)

| سیکشن                          | یہ کیا قابو کرتا ہے                                                                                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **عمومی**                      | زبان اور علاقہ (اعداد اور تاریخ کی شکل، ہفتے کا پہلا دن)، 24 گھنٹے کی گھڑی، اسٹارٹ اپ ورک اسپیس، آٹو سیو وقفہ، تصدیقیں (آرڈرز، Flatten all، ونڈو بند کرنا، باہر نکلنا)، آٹو لاک |
| **ظاہری شکل**                  | تھیم، 29 ٹوکن والا رنگ ایڈیٹر، UI اسکیل، فونٹ سائز، صرف آئیکنز والا ربن                                                                                                         |
| **لے آؤٹ**                     | Snap to grid، فاصلے، لے آؤٹ لاک، ہیڈر کی گنجانی اور انداز، لے آؤٹ ٹیبز کی جگہ، نئی ونڈوز کہاں کھلیں، لنک گروپ رنگ، ملٹی مانیٹر بحالی                                            |
| **چارٹ**                       | ڈیفالٹ موڈ اور ٹائم فریم، auto-scroll، کینڈل کے رنگ، پس منظر، گرڈ، محور اور اسکیل، crosshair، legend اور status لائن                                                            |
| **Footprint**                  | سیل کا مواد، رنگ بندی، فونٹ اور سیل سائز، imbalance ratio اور رنگ، POC اور value area، خلاصہ قطاریں                                                                             |
| **ہیٹ میپ**                    | پیلیٹ، contrast، normalisation، کم از کم آرڈر سائز، ہسٹری کی گہرائی، overlays، bubbles                                                                                          |
| **DOM**                        | قطار کی اونچائی، فونٹ، auto-centre، ڈیفالٹ grouping، big-lot حد، کلک بٹنز کی ادلا بدلی                                                                                          |
| **ٹیپ**                        | رکھی جانے والی قطاریں، کم از کم سائز، نئے ٹریڈز کی پیروی، ملی سیکنڈ، big-trade حد، beep                                                                                         |
| **ٹریڈنگ**                     | ڈیفالٹ مقدار، پری سیٹس، آرڈر کی قسم، time in force، one-click، ہاٹ کیز، slippage رواداری، خودکار SL / TP، آرڈر اور پوزیشن لائنیں                                                |
| **ڈیٹا**                       | پرووائیڈر کی ترجیح، auto-reconnect اور back-off، ٹائم اسٹیمپ کا ماخذ، depth conflation، live ticks ریکارڈ کرنا، cache سائز                                                      |
| **الرٹس**                      | فعال، پاپ اپ، ونڈو flash، ڈیفالٹ تکرار، expiry، cool-down، زیادہ سے زیادہ فعال                                                                                                  |
| **رسک**                        | روزانہ نقصان، پوزیشن اور آرڈر سائز، فی دن ٹریڈز، قیمت کی حد، وارننگ کی سطح، حد ٹوٹنے پر عمل، lock کی مدت                                                                        |
| **ہاٹ کیز**                    | ہر کمانڈ کے لیے کی ریکارڈ کریں، تصادم، scopes، پری سیٹس، ایکسپورٹ / درآمد                                                                                                       |
| **آوازیں**                     | خاموش، ماسٹر والیوم، سات واقعاتی آوازیں، آپ کی اپنی `.wav` / `.mp3`                                                                                                             |
| **ٹائم زونز**                  | ایپلیکیشن، چارٹ محور اور کیلنڈر کے ٹائم زونز، ایکسچینج گھڑیاں اور hover وقت                                                                                                     |
| **کمیشن**                      | کرپٹو maker اور taker فیس، فیوچرز round-turn کمیشن، اکاؤنٹ اور انسٹرومنٹ کے لحاظ سے اصول                                                                                        |
| **ڈیٹا میں تاخیر**             | امبر / سرخ اسٹیٹس pills کے لیے latency کی حدیں                                                                                                                                  |
| **کارکردگی**                   | رینڈرر، ویڈیو اڈاپٹر، FPS حد، worker threads، debug overlay، چھپی ہوئی ونڈو کی رینڈرنگ                                                                                          |
| **مشترکہ سیٹنگز**              | Value area فیصد، فی چارٹ زیادہ سے زیادہ کینڈلز، ڈیفالٹ لوڈ دن، ریکارڈر کی ڈسک حد اور برقراری، اطلاعات، جدول، AI اسسٹنٹ بٹن                                                      |
| **رازداری اور سیکیورٹی**       | ٹیلی میٹری (بند)، کریش رپورٹس، اکاؤنٹ نمبر چھپانا، بیلنس چھپانا، لاگ آؤٹ پر caches صاف کرنا، سب کچھ ری سیٹ کرنا، AI کو اسکرین شاٹس اور کانٹیکسٹ بھیجنا                          |
| **لاگز**                       | لاگ کی سطح اور میموری میں اندراجات                                                                                                                                              |
| **حسب ضرورت ماڈیولز**          | ونڈوز کو فعال یا غیر فعال کرنا                                                                                                                                                  |
| **ہمارے بارے میں اور اپ ڈیٹس** | ورژن، اپ ڈیٹ کی جانچ اور چینل (Stable یا Beta)                                                                                                                                  |
