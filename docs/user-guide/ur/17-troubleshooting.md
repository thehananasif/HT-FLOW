## اکاؤنٹس

**میں پاس ورڈ بھول گیا۔** لاگ اِن ← _پاس ورڈ بھول گئے؟_ ← صارف نام، 24 الفاظ کا ریکوری کوڈ اور نیا پاس ورڈ۔ کوڈ کے بغیر ڈیٹا بحال نہیں ہو سکتا۔

**PIN نے کام کرنا چھوڑ دیا۔** پانچ غلط PIN کے بعد وہ ہٹا دیا جاتا ہے۔ پاس ورڈ سے لاگ اِن کریں اور نیا PIN لگائیں (اکاؤنٹ مینو ← Change PIN…)۔

**Windows کہتا ہے "Windows protected your PC"۔** انسٹالر پر ابھی کوڈ سائننگ نہیں ہوئی: **More info ← Run anyway**۔

## ڈیٹا اور کنکشنز

**کسی ایکسچینج کا pill سرخ ہے یا Binance ایرر دکھا رہا ہے۔** **Connections** کھولیں اور اسٹیٹس کا متن دیکھیں۔ اپنا انٹرنیٹ اور فائر وال چیک کریں۔ کچھ ایکسچینجز علاقے بلاک کرتے ہیں (HTTP 451)۔

**کنکشن کہتا ہے "Desktop app only"۔** ایکسچینج APIs براؤزر سے کال نہیں ہو سکتے۔ Windows ایپ استعمال کریں۔

**چارٹ خالی ہے یا no data کہتا ہے۔** یقینی بنائیں کہ انسٹرومنٹ کی فیڈ ہے (پکر کا اسٹیٹس کالم)، ہسٹری لوڈ ہونے کے لیے ذرا انتظار کریں، یا `Ctrl+R` دبائیں۔ `Chart: Reload all historical data` دوبارہ لوڈ پر مجبور کرتی ہے۔ جن انسٹرومنٹس پر _No feed_ لکھا ہو ان کا ابھی کوئی کنیکٹر نہیں۔

**پرانی بارز ہموار لگتی ہیں یا footprint کی تفصیل نہیں۔** ایکسچینجز پرانے دنوں کے لیے صرف کینڈلز دیتے ہیں، اس لیے ان بارز کے buy / sell والیوم کا تخمینہ ہوتا ہے (Binance پر درست)۔ درست ہسٹری کے لیے recorder کو live ڈیٹا محفوظ کرنے دیں۔

**ڈیٹا دیر سے آتا لگتا ہے۔** امبر / سرخ اسٹیٹس pills کا مطلب ہے latency Settings ← ڈیٹا میں تاخیر کی حدوں سے اوپر ہے۔ اپنا نیٹ ورک اور Settings ← ڈیٹا میں _Depth conflation_ چیک کریں۔

## کارکردگی

**ایپ سست ہے یا پنکھا چل رہا ہے۔** Settings ← کارکردگی کھولیں: FPS حد کم کریں، _Disable hidden windows rendering_ آن کریں، **Default load days** اور _Maximum candles per chart_ کم کریں، غیر استعمال شدہ heatmap ونڈوز بند کریں، یا 3D heatmap بند کریں۔ زیادہ زوم آؤٹ کرنے پر footprint کینڈلز میں سمٹ جاتا ہے۔

**Heatmap خالی ہے۔** اسے آرڈر بک depth چاہیے؛ depth والا ایکسچینج جوڑیں یا سمیولیٹر استعمال کریں۔ Depth ہسٹری ونڈو کھلنے کے لمحے سے جمع ہوتی ہے۔

## ٹریڈنگ

**آرڈرز مسترد ہو رہے ہیں یا کچھ نہیں ہو رہا۔** lock آئیکن (DOM / چارٹ lock)، Risk (لاک شدہ اکاؤنٹ ٹائٹل بار میں _Locked_ دکھاتا ہے)، منتخب پیپر اکاؤنٹ اور _Order confirmations_ چیک کریں۔ Trading Activity ونڈو ہر رد کی وجہ بتاتی ہے۔

**کوئی کی کچھ نہیں کرتی۔** scope والی ہاٹ کیز صرف تب کام کرتی ہیں جب آخری کلک اسی قسم کی ونڈو میں ہوا ہو۔ Settings ← ہاٹ کیز میں تصادم چیک کریں۔

## پھر بھی مسئلہ حل نہیں ہوا؟

- **Logs** کھولیں اور مسئلے کے آس پاس کی لائنیں کاپی یا ایکسپورٹ کریں۔
- Help مینو ← **Report a problem…**۔
- Help مینو ← _Check for updates_ سے اپ ڈیٹ کریں۔
