## آپ کا ڈیٹا کہاں رہتا ہے

| آئٹم                                                 | مقام                                                                              |
| ---------------------------------------------------- | --------------------------------------------------------------------------------- |
| پروفائلز (سیٹنگز، ورک اسپیسز، جرنل، ٹیمپلیٹس، vault) | `%APPDATA%\HTFlow\` (پورٹیبل: exe کے ساتھ `data\`)، XChaCha20-Poly1305 سے سیل شدہ |
| Tick ہسٹری                                           | ڈیٹا فولڈر کے اندر `ticks\`                                                       |
| کریش رپورٹس                                          | ڈیٹا فولڈر کے اندر `crashes\`؛ redacted، کہیں نہیں بھیجی جاتیں                    |

## بیک اپس

HT Flow میں کلاؤڈ sync نہیں ہے، اس لیے بیک اپ آپ خود بناتے ہیں:

1. **اکاؤنٹ مینو ← Export profile (.htprofile)** ایک یوزر کا سب کچھ ایک فائل میں لکھتا ہے جو اسی یوزر کے پاس ورڈ سے انکرپٹڈ رہتی ہے۔ اسے کسی بھی PC پر لاگ اِن اسکرین سے درآمد کریں۔
2. **Workspaces manager ← Export** اور چارٹ ٹیمپلیٹس ایسی فائلوں میں ایکسپورٹ ہوتے ہیں جنہیں آپ version control میں رکھ سکتے ہیں۔
3. HT Flow بند ہونے پر پورا ڈیٹا فولڈر کاپی کرنے سے ہر پروفائل اور tick store کا بیک اپ بن جاتا ہے۔

> **خودکار بیک اپس** Settings ← مشترکہ سیٹنگز ← _Backup period_ اور _Maximum store backups_ اس شیڈول پر (اسٹارٹ اپ اور روزانہ جانچ کے ساتھ) آپ کے پروفائل فولڈر کو ڈیٹا فولڈر میں `backups\<date-time>\` میں کاپی کرتے ہیں اور زیادہ سے زیادہ تعداد سے پرانے حذف کر دیتے ہیں۔ **Back up now** اور **Open backups folder** اسی صفحے پر اور Command Palette میں ہیں۔
>
> **لاگ فائلیں** روزانہ لاگ فولڈر میں لکھی جاتی ہیں (Settings ← لاگز، ڈیفالٹ ڈیٹا فولڈر کے اندر `logs\`) جن سے پاس ورڈز اور کلیدیں ہٹا دی جاتی ہیں؛ _Keep days_ سے پرانی فائلیں اسٹارٹ اپ پر حذف ہوتی ہیں۔ **Open log folder** اسے کھولتا ہے۔

بحال کرنے کے لیے لاگ اِن اسکرین پر `.htprofile` درآمد کریں، یا ڈیٹا فولڈر واپس کاپی کریں۔ پاس ورڈ یا ریکوری کوڈ کے بغیر پروفائل نہیں کھل سکتا۔

## لاگز

![Logs ونڈو](images/logs-window.webp)

**Logs** ونڈو (ربن) ایپ کے اندر کا ring buffer ہے جو بتاتا ہے کہ HT Flow کیا کر رہا ہے، بشمول پکڑا گیا `console.error` آؤٹ پٹ، غیر سنبھالی گئی غلطیاں اور unhandled promise rejections۔

- **level** اور **source** سے فلٹر کریں، یا متن تلاش کریں۔
- **Pause** منظر کو منجمد کرتا ہے جبکہ ریکارڈنگ جاری رہتی ہے۔ **Copy**، **Export .txt** اور **Clear** اس پر عمل کرتے ہیں جو آپ دیکھ رہے ہیں۔
- Settings ← لاگز سطح اور میموری میں رکھے جانے والے اندراجات کی تعداد طے کرتی ہے۔

## کریش رپورٹس اور مسئلے کی رپورٹس

اگر HT Flow کریش ہو تو `crashes\` میں ایک redacted رپورٹ (URLs میں ٹوکن اور query قدریں ہٹا کر) لکھی جاتی ہے۔ **Report a problem…** (Help مینو) اسی قسم کی معلومات جمع کرتا ہے تاکہ آپ اسے کسی issue کے ساتھ لگا سکیں۔ کچھ بھی خود بخود اپ لوڈ نہیں ہوتا؛ ٹیلی میٹری بند ہے۔
