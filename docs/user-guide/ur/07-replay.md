Replay ریکارڈ شدہ یا سمیولیٹڈ آرڈر فلو کو **ایک گھڑی** پر چلاتا ہے، اس لیے چارٹس، DOM اور ٹیپ replay کے وقت کے بعد کا کچھ نہیں دکھاتے۔ مشق کا یہ محفوظ طریقہ ہے: آپ الگ replay پیپر اکاؤنٹ پر ٹریڈ کرتے ہیں اور fills پر replay کا وقت لگتا ہے۔

## فوری ڈیمو

کمانڈ **Load sample replay session** چلائیں۔ یہ سمیولیٹڈ CLZ6 کنٹریکٹ کا ایک مقررہ، seed شدہ گھنٹہ چلاتی ہے، جو ہر بار ایک جیسا ہوتا ہے، اور کنٹرولز کھول دیتی ہے۔

![نمونہ replay سیشن](images/replay-sample.webp)

## اپنا replay ترتیب دیں

![Replay ونڈو](images/replay-window.webp)

1. ربن سے **Replay** کھولیں۔ یہ اپنی الگ تقسیم میں کھلتا ہے۔
2. ایک یا زیادہ **انسٹرومنٹس** شامل کریں (یہ ہم وقت چلتے ہیں) اور **وقت کی رینج** چنیں۔ ذرائع مقامی tick store، درآمد شدہ CSV ڈیٹا ("Imported files") اور سمیولیٹر ہیں۔
3. **Start** دبائیں۔ replay فیڈ استعمال کرنے والے چارٹس پر جامنی **Replay** بیج لگ جاتا ہے۔
4. چاہیں تو سیٹ اپ کو **replay ٹیمپلیٹ** کے طور پر محفوظ کریں (bookmarks اور loop ساتھ محفوظ ہوتے ہیں)۔

## کنٹرولز

| کنٹرول           | کیا کرتا ہے                                               |
| ---------------- | --------------------------------------------------------- |
| `Space`          | Play / pause                                              |
| `Right` / `Left` | ایک بار آگے / پیچھے                                       |
| `Shift+Right`    | ایک tick آگے                                              |
| `1` – `9`        | رفتار کے پری سیٹس (0.25× سے 1000× تک)                     |
| Timeline         | چھلانگ کے لیے گھسیٹیں؛ اس پر economic-event نشان ہوتے ہیں |
| **Go to time**   | کسی ٹائم اسٹیمپ پر جائیں                                  |
| **Bookmarks**    | لمحات محفوظ کریں اور ان پر واپس آئیں                      |
| **Loop**         | کسی رینج کو دہرائیں                                       |
| **Sync**         | کئی انسٹرومنٹس کو ایک ہی وقت پر رکھیں                     |

کیز اس وقت کام کرتی ہیں جب replay کنٹرولز فوکس میں ہوں (scope _replay_)۔

## مستقبل کی بارز چھپائیں

**Hide future bars** آن کریں تو چارٹ صرف replay کے وقت تک نظر آتا ہے، اور بننے والی بار کے لیے ghost کینڈلز ہوتی ہیں۔ مستقبل کا ڈیٹا store میں کبھی نہیں جاتا، اس لیے انڈیکیٹرز جھانک نہیں سکتے۔

## Replay میں ٹریڈنگ

آرڈرز **replay پیپر اکاؤنٹ** میں جاتے ہیں (اکاؤنٹ پکر بتاتا ہے کہ کون سا اکاؤنٹ روٹ ہو رہا ہے)۔ Entries اور exits پر چارٹ پر replay کے وقت کے ساتھ **B / S ٹیگز** لگتے ہیں۔ Brackets، ATM ٹیمپلیٹس اور DOM بالکل live پیپر ٹریڈنگ کی طرح چلتے ہیں۔ اگر آپ نہیں چاہتے کہ جرنل میں کوئی کھلی پوزیشن رہے تو replay چھوڑنے سے پہلے روکیں اور flatten کریں۔

## اسٹریٹجیز کے لیے Replay

بیک ٹیسٹ بھی replay ڈیٹاسیٹس پر چلتے ہیں؛ دیکھیں [اسٹریٹجیز اور بیک ٹیسٹنگ](11-strategies-backtesting.md)۔ غائب ڈیٹا کا ڈاؤن لوڈ ابھی دستیاب نہیں: tick recorder سے ڈیٹا ریکارڈ کریں یا CSV درآمد کریں ([Data manager](14-data-manager.md))۔
